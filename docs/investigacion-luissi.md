# Investigación de materiales — Barraca Luissi (luissi.com.uy)

Relevamiento realizado el **27/09/2026** sobre https://luissi.com.uy. Todos los nombres, precios, monedas, medidas y URLs de este documento fueron copiados de la web de Luissi (**Dato Luissi**). Lo que no figura en la web se indica como "no indicado". Las interpretaciones propias se marcan como **Cálculo/Inferencia propia**.

## Notas generales

- **Moneda:** el selector de la web ("Según producto") muestra cada producto en su moneda de origen: **USD** para tableros, herrajes, Titebond, Bona, Milesi; **$ (pesos)** para pino nacional, Fanacola, Lusol, Crisoles, etc. **No se publica ninguna cotización.** Todos los productos elegidos para los diseños están en **USD**, así que los totales quedan en una sola moneda y no hay que convertir nada.
- **IVA:** ninguna página indica si los precios incluyen IVA → consultar.
- **Stock:** muchos productos muestran stock "1" o "sin stock/preventa". Hay que confirmar el stock antes de comprar.
- **Unidad de venta:** el carrito dice "Unidades" en todos los productos. Cuando la descripción aclara otra base ("precio por 100 unidades", "PRECIO POR PIE", "PRECIO POR KILO", "PRECIO POR M2"), se usa esa base.
- **URL de producto:** `https://luissi.com.uy/p/<slug>/<id>/<id>`.
